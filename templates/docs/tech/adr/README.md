# Architecture decision records

An ADR records a decision that is hard to reverse, is a surprise, and has a real
trade-off. Copy [template.md](template.md) to `NNNN-<title>.md`. Use the next free
number. Add a row to the index below.

Do not change the decision of an accepted ADR. To change it, write a new ADR that
replaces the old ADR, and link the two ADRs.
