# Technical docs

This folder contains the docs about architecture and technical questions. The docs tell
how the product works now. The documenter agent keeps them the same as the code.

| Doc | Content | Owner |
|-----|---------|-------|
| [architecture.md](architecture.md) | components, data flow, data model, integrations | documenter |
| [api.md](api.md) | endpoints, request and response types, error codes | documenter |
| [configuration.md](configuration.md) | environment variables, configuration keys, feature flags | documenter |
| [adr/](adr/README.md) | architecture decision records | architect |
| [runbooks/](runbooks/README.md) | procedures for failures that occurred more than one time | learn-loop skill |

Feature-specific technical plans (`plan.md`, `tasks.md`) are in the feature folders in
[docs/features/](../features/README.md).
